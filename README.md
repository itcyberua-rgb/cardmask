# CardMask

Локальный браузерный форматтер тестовых карточных строк.

## Возможности

- вставка текста или загрузка `.txt`, `.log`, `.csv`, `.json` до 50 МБ;
- drag-and-drop файлов;
- поиск записей формата `номер | MM | YY | CVV` даже внутри большого текста;
- проверка формата и алгоритма Луна;
- безопасный вывод только с маской номера и `[удалено]` вместо CVV;
- отсутствие сервера, базы данных, `localStorage` и сетевой передачи исходного текста.

## Запуск

Откройте `index.html` в браузере или запустите статический сервер:

```bash
python3 -m http.server 3000
```

Затем откройте `http://localhost:3000`.

Используйте только синтетические тестовые данные платёжного провайдера.
