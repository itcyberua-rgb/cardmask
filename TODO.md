# Готовые результаты

- [x] Многострочное поле для вставки исходного текста с записями формата `номер|месяц|год|CVV`.
- [x] Локальный поиск и разбор подходящих строк непосредственно в браузере, без сервера и базы данных.
- [x] Проверка структуры каждой записи, включая состав и формат номера карты, месяца, года и CVV.
- [x] Проверка номера карты по алгоритму Луна.
- [x] Безопасный результат с номером в формате первых 4 и последних 4 цифр, месяцем, годом и пометкой `[удалено]` вместо CVV.
- [x] Полные номера карт и CVV не отображаются в результатах, сообщениях и сводке и не сохраняются приложением.
- [x] Кнопка обработки введённого текста.
- [x] Кнопка полной очистки ввода, результатов, сводки и сообщений.
- [x] Выбор текстового файла до 5 МБ с чтением только локально в браузере.
- [x] Сводка количества найденных, прошедших проверку и ошибочных строк.
- [x] Список безопасных результатов и понятные русскоязычные сообщения об ошибках без раскрытия чувствительных данных.
